## RSVP
Ganti `6280000000000` di `script.js` dengan nomor WhatsApp tujuan.

## Nama tamu personal
Tambahkan `?to=Nama%20Tamu` di belakang URL. Contoh:
`https://USERNAME.github.io/REPO/?to=Bapak%20Andi`

## Upload ke GitHub Pages
Buat repository, upload seluruh isi folder, lalu Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
